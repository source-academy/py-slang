of the textbook
<a href="https://sourceacademy.org/sicpy">Structure and Interpretation
of Computer Programs, Python Adaptation</a> (SICPy).

## How can you watch your program run?

In Python §3 and §4, programs have state: an assignment changes a variable or a list, and what a call
of a function does depends on the environment in which the function was defined. The
playground's <strong>E-Stepper</strong> tab, the environment stepper, shows how your program runs, one small
step at a time. Press <em>Run</em>, then drag the slider, or use the buttons or the keys
<code>f</code> (next step) and <code>b</code> (previous step).

In each step, the program is rewritten: the part that is evaluated next, and then its result, are
highlighted. The body of a function that is being evaluated is marked with a coloured bracket
that names the frame in which it runs (<code>E1</code>, <code>E2</code>, ...), and lists and function
objects are shown as small badges (<code>#1</code>, <code>#2</code>, ...) that refer to the objects
drawn in the environment diagram next to the program. Read
<a href="../e-stepper/index.html">the guide to the environment stepper</a> to learn what the brackets,
labels and badges mean.
